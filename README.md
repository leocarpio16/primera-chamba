# Primera chamba

Recomendador de vacantes que, a partir de tu perfil, te sugiere las ofertas que mejor te quedan y te arma un CV
adaptado a cada una, usando solo lo que tú sabes hacer.

Proyecto semestral de Datos Masivos II. Especificación en [`docs/PRD.md`](docs/PRD.md).

## Configuración

```bash
pip install -r requirements.txt
cp .env.example .env   # y pon tu GEMINI_API_KEY (opcional; sin ella el CV se arma por reglas)
```
